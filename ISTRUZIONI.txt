SKYTRACE — RADAR AEREO
======================

CONTENUTO
- public/index.html    Interfaccia del radar circolare (HTML, CSS, JavaScript)
- public/_worker.js    Cloudflare Pages Advanced Mode: endpoint API + pubblicazione asset statici
- AVVIA_LOCALHOST.bat Avvio rapido per Windows
- avvia_localhost.py  Server locale e proxy ADS-B; prova le porte 10000, 10001, ... 10100
- ISTRUZIONI.txt       Questa guida

TEST LOCALE (WINDOWS)
1. Estrai tutto lo ZIP mantenendo la cartella public e i file nella stessa cartella.
2. Installa Python 3 se non è già installato: https://www.python.org/downloads/
3. Fai doppio clic su AVVIA_LOCALHOST.bat.
4. Si aprirà il browser su http://127.0.0.1:10000 (o sulla prima porta libera successiva).
5. Per verificare il proxy, apri in un'altra scheda /api/health sullo stesso indirizzo, ad esempio http://127.0.0.1:10000/api/health. Deve apparire un JSON con "ok": true.
6. Lascia aperta la finestra del server mentre provi il radar. Per fermarlo premi Ctrl+C.

PUBBLICAZIONE SU GITHUB + CLOUDFLARE PAGES
1. Nel repository GitHub carica/sostituisci i contenuti di questo ZIP alla radice del repository, non dentro un'altra cartella.
2. Verifica che public/index.html e public/_worker.js siano entrambi presenti su GitHub.
3. Se nel repository è rimasta la vecchia cartella functions/api/aircraft.js, puoi eliminarla per evitare confusione: il nuovo public/_worker.js usa Cloudflare Pages Advanced Mode e prende il posto del sistema functions/.
4. In Cloudflare Pages, Root directory vuoto, Framework preset None, Build command exit 0 (oppure vuoto), Build output directory public, branch main.
5. Avvia un nuovo deployment e attendi Success.
6. Test diagnostico: apri https://TUO-PROGETTO.pages.dev/api/health. Deve rispondere con JSON simile a {"ok":true,"service":"SKYTRACE Pages Worker","mode":"advanced"}. Se invece mostra HTML/404, il deployment non sta usando public/_worker.js oppure il file non è stato caricato nella cartella corretta.
7. Poi apri https://TUO-PROGETTO.pages.dev e premi Aggiorna. Il radar usa /api/aircraft come proxy della fonte ADS-B.

CONFIGURAZIONE CLOUDFLARE PAGES
- Framework preset: None
- Build command: exit 0
- Build output directory: public
- Root directory: vuoto
- Production branch: main

DATI LIVE
- Fonte: https://www.adsb.lol/
- I dati vengono aggiornati ogni 20 secondi; copertura, disponibilità e limiti della fonte possono cambiare.
- Non vengono inventati aerei in caso di errore API.
- Geolocalizzazione browser disponibile solo su localhost o HTTPS.
- Questa app è una visualizzazione informativa, non va usata per navigazione o decisioni di sicurezza.
