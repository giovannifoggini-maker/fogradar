SKYTRACE — RADAR AEREO
======================

CONTENUTO
- public/index.html    Interfaccia radar circolare (HTML, CSS, JavaScript)
- public/_worker.js    Cloudflare Pages Advanced Mode: asset statici + proxy ADS-B
- AVVIA_LOCALHOST.bat Avvio rapido per Windows
- avvia_localhost.py  Server locale e proxy ADS-B
- ISTRUZIONI.txt       Questa guida

TEST LOCALE (WINDOWS)
1. Estrai tutto lo ZIP mantenendo la cartella public e i file nella stessa cartella.
2. Installa Python 3 se non è già installato: https://www.python.org/downloads/
3. Fai doppio clic su AVVIA_LOCALHOST.bat.
4. Si apre il browser su http://127.0.0.1:10000 (o sulla prima porta libera successiva).
5. Per verificare il proxy, apri /api/health sul medesimo indirizzo. Deve apparire JSON con "ok": true.
6. Il proxy prova tre fonti live in sequenza: ADSB One, Airplanes.live e ADSB.lol. Se una risponde 403, con HTML o non JSON, prova la successiva.
7. Per arrestare il server premi Ctrl+C nella finestra del terminale.

PUBBLICAZIONE SU GITHUB + CLOUDFLARE PAGES
1. Carica/sostituisci i contenuti di questo ZIP alla radice del repository GitHub, non dentro un'altra cartella.
2. Verifica che public/index.html e public/_worker.js siano entrambi presenti su GitHub.
3. Se esiste la vecchia cartella functions/api/aircraft.js, rimuovila per evitare confusione: il proxy usa Pages Advanced Mode tramite public/_worker.js.
4. In Cloudflare Pages: Root directory vuoto, Framework preset None, Build command exit 0 (oppure vuoto), Build output directory public, production branch main.
5. Avvia un nuovo deployment e attendi Success.
6. Test diagnostico: apri https://TUO-PROGETTO.pages.dev/api/health. Deve rispondere JSON con "ok": true e l'elenco dei provider.
7. Poi apri la home e premi Aggiorna.

FONTI DATI
- ADSB One: https://api.adsb.one/ — endpoint documentato: /v2/point/{lat}/{lon}/{radius}
- Airplanes.live: https://airplanes.live/api-docs/ — endpoint documentato: /v2/point/{lat}/{lon}/{radius}
- ADSB.lol: https://www.adsb.lol/ — endpoint v2 per latitudine/longitudine/raggio.

Il proxy prova le fonti una dopo l'altra se riceve HTTP non riuscito, HTML invece di JSON, JSON malformato o errore di connessione. La disponibilità, copertura, policy anti-abuso e limiti possono variare per ciascun servizio. L'app non inventa posizioni quando i dati live non sono disponibili.

AGGIORNAMENTO
- Intervallo di aggiornamento della mappa: 20 secondi.
- Coordinate iniziali: Milano. È possibile scegliere geolocalizzazione (su localhost/HTTPS) o coordinate manuali.
- Raggi disponibili: 25, 50, 100, 150 e 250 miglia nautiche.
- Questa app è solo informativa: non usarla per navigazione o decisioni di sicurezza.
