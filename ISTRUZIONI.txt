SKYTRACE — RADAR AEREO LIVE GRATUITO
===================================

IMPORTANTE: non ci sono coordinate preimpostate. Alla prima apertura il radar e' vuoto,
perche' devi scegliere tu il centro usando il GPS oppure inserendo le coordinate.

NESSUNA INSTALLAZIONE MANUALE
-----------------------------
Il pacchetto contiene il codice e gli script per predisporre gli strumenti portatili.
Al primo avvio, se mancanti, AVVIA_LOCALHOST.bat scarica il runtime Python portatile
ufficiale nella cartella tools del progetto. AVVIA_LIVE_TUNNEL.bat prepara anche
cloudflared.exe nella stessa cartella. Non vengono installati programmi nel sistema
Windows e non servono comandi da digitare. E' necessaria una connessione Internet
solo per il primo scaricamento e per ricevere i dati live.
I file scaricati vengono controllati con SHA-256 prima di essere eseguiti.

1. RADAR LOCALE
--------------
1. Estrai tutto lo ZIP in una cartella normale, non dentro l'anteprima dello ZIP.
2. Fai doppio clic su AVVIA_LOCALHOST.bat.
3. Al primo avvio attendi che scarichi il runtime portatile ufficiale; verra' salvato
   in tools\python, dentro la cartella del progetto.
4. Il browser si apre su localhost alla prima porta libera tra 10000 e 10100.
5. Per fermare il server premi CTRL+C nella finestra del terminale.

2. SCEGLI LA POSIZIONE (NESSUNA POSIZIONE PREIMPOSTATA)
------------------------------------------------------
- Premi “Usa la mia posizione” e consenti al browser di rilevare la posizione, oppure
- scrivi latitudine e longitudine nei due campi vuoti e premi “Imposta coordinate”.
- Il radar non invia richieste alle API e non mostra un centro geografico finche' non
  scegli una posizione.
- Dopo aver scelto il centro, il radar interroga le quattro fonti pubbliche in sequenza:
  ADSB One, Airplanes.live, ADSB.lol e ADSB.fi.
- Le fonti possono limitare o bloccare le richieste; il pacchetto mostra solo aerei reali
  effettivamente ricevuti e non inventa bersagli.

3. RADAR LIVE ACCESSIBILE DA INTERNET (OPZIONALE)
------------------------------------------------
1. Estrai lo ZIP e fai doppio clic su AVVIA_LIVE_TUNNEL.bat.
2. Al primo avvio il launcher scarica Python portatile e cloudflared nella cartella tools.
   Non occorre aprire siti per scaricare componenti a mano e nulla viene installato
   fuori dalla cartella del progetto.
3. Il terminale mostra un indirizzo https://....trycloudflare.com, username “skytrace”
   e una password generata. Il browser si aprira' sull'indirizzo del tunnel.
4. Quando chiede le credenziali, usa lo username e la password visibili nel terminale.
   Non condividere la password.
5. Mantieni aperti il terminale e il PC. Il tunnel e' temporaneo e il suo indirizzo cambia
   quando lo riavvii. Per interromperlo premi CTRL+C.

NOTA: il tunnel usa lo stesso proxy Python del localhost, cosi' le richieste ADS-B partono
   dalla connessione del tuo PC invece che dagli IP dei server Cloudflare Pages. Non elimina
   eventuali blocchi del provider. Se tutte le fonti rifiutano la richiesta, SKYTRACE mostra
   un avviso e non disegna aerei falsi. Per un collegamento live via tunnel, apri la URL
   trycloudflare.com mostrata dal launcher; la versione statica pages.dev non puo' usare
   il server del tuo PC quando e' spento.

4. PUBBLICAZIONE STATICA GITHUB + CLOUDFLARE PAGES
-------------------------------------------------
La cartella public contiene la pagina e il Worker. Per un sito statico su Cloudflare Pages:
- Root directory: vuoto
- Framework preset: None
- Build command: exit 0 (oppure vuoto)
- Build output directory: public
- Branch: main
Nota: il dominio pages.dev usa la propria infrastruttura per chiamare i provider e puo'
ricevere 403/429 anche quando localhost funziona. Per condividere il feed del PC mentre
resta acceso, usa l'URL Quick Tunnel della sezione 3.
