SKYTRACE — RADAR AEREO (fonti ADS-B pubbliche)
================================================

Questa versione resta sulle tre fonti pubbliche originali, in sequenza:
1. ADSB One
2. Airplanes.live
3. ADSB.lol

Non servono credenziali o chiavi API per configurare l'app. La disponibilità
non è garantita: i provider possono limitare richieste (403/429), soprattutto
da alcuni server cloud. In tal caso il radar non interrompe la pagina: conserva gli ultimi dati ricevuti
per la stessa area (marcandoli come NON LIVE) e usa tentativi progressivamente
più distanziati. Se non è mai arrivato un dato reale, mostra uno stato informativo.
Non inventa posizioni o dati degli aeromobili.

1. TEST LOCALE (WINDOWS)
- Estrai tutto lo ZIP mantenendo la struttura delle cartelle.
- Installa Python 3, se necessario: https://www.python.org/downloads/
- Fai doppio clic su AVVIA_LOCALHOST.bat.
- Il server prova porte da 10000 a 10100 e apre il browser sulla prima libera.
- Il proxy tenta ADSB One, poi Airplanes.live, poi ADSB.lol.
- Per fermare il server premi CTRL+C nella finestra del terminale.

2. PUBBLICAZIONE SU GITHUB + CLOUDFLARE PAGES
Carica alla radice del repository questi contenuti, mantenendo le cartelle:
  public/index.html
  public/_worker.js
  AVVIA_LOCALHOST.bat
  avvia_localhost.py
  ISTRUZIONI.txt
  .gitignore

In Cloudflare Pages configura:
- Root directory: vuoto
- Framework preset: None
- Build command: exit 0 (oppure vuoto)
- Build output directory: public
- Production branch: main

Salva le modifiche su GitHub e attendi che Cloudflare termini il nuovo deployment.

3. VERIFICA
- Apri https://TUO-PROGETTO.pages.dev/api/health
- Deve rispondere JSON con "ok": true e l'elenco dei tre provider.
- Apri https://TUO-PROGETTO.pages.dev/api/aircraft?lat=45.4642&lon=9.19&dist=50
- Se una fonte risponde correttamente, la risposta conterrà il campo "ac".
- Poi apri la home del radar.

NOTE IMPORTANTI
- Il radar verifica i dati ogni 60 secondi, ma dopo errori applica un'attesa progressiva
  fino a 10 minuti. Anche il proxy mette in pausa temporanea le fonti dopo 403/429.
- Gli ultimi dati riusciti vengono conservati nel browser per 24 ore e, durante un
  disservizio, sono marcati chiaramente come NON LIVE. Se non esiste una lettura
  precedente, la pagina mostra uno stato informativo e non inventa aerei.
- Il proxy passa alla fonte successiva quando la precedente fallisce. Se tutte
  restituiscono 403/429, non è un problema del disegno radar: l'accesso alle API
  è rifiutato o limitato dall'infrastruttura/provider. Attendi e riprova più tardi.
- I dati possono avere ritardi, copertura incompleta o campi mancanti.
- Questa app è solo informativa e non va usata per navigazione o decisioni di sicurezza.
